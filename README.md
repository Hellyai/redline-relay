# Redline Relay

Redline Relay 是一个用于多轮协议谈判的 Codex 技能。把我方发出稿、对方回稿和上一轮台账交给 Codex，即可按议题追踪本轮改动、我方建议和待确认事项。适用于投资协议、股东协议、合伙协议及附属协议。

## 安装

将仓库下载或克隆到本地，把包含 [SKILL.md](SKILL.md) 和 [scripts/](scripts/) 的整个 `redline-relay` 文件夹放入 Codex 的用户技能目录 `~/.codex/skills/`（Windows 对应 `%USERPROFILE%\.codex\skills\`）。开启新会话后，用 `$redline-relay` 调用。正文和批注提取脚本使用 Python 3 标准库。

## 每轮怎么用

1. 提供我方上一轮发出稿、对方本轮回稿（`.docx`）以及上一轮台账。首次使用可以先用两版稿件建账。
2. 标明版本日期、比较方向和我方代表的主体。已有确认结论或谈判口径时一并提供。
3. 在 Codex 中发出类似指令：

> 使用 $redline-relay 对比 5 月 10 日我方发出稿与 5 月 14 日对方回稿，沿用上一轮议题编号，更新谈判台账。

## 会得到什么

- **本轮议题**按「主题 → 概要 → 原文及差异 → 我方立场与修改建议 → 超链接」呈现。标明文件名称、版本日期和条款位置，原文逐字保留。
- **跨协议联动**把多人针对同一事项的批注归并。投资协议与股东协议各自比较，再检查关联条款是否需要同步修改。
- **已结束事项**保留前轮编号和结束依据。未再修改的议题按流程结束处理；仍有明确修改要求或未解决的联动冲突时继续跟踪。

提取脚本在本地读取 Word 正文和批注，输出 JSON 供 Codex 分析。接受结论是有依据的审阅建议，双方是否确认以沟通记录为准。
